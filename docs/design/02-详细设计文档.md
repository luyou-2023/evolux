## 2. 核心数据结构

### 2.1 路由相关

```python
@dataclass
class SkillCandidate:
    skill_name: str
    score: float
    description: str = ""
    match_source: str = "keyword"  # keyword | vector

@dataclass
class SubAgentCandidate:
    agent_id: str
    vector_score: float
    name: str = ""
    domain: str = ""
    skills: list[str] = field(default_factory=list)

@dataclass
class FusedCandidate:
    agent_id: str
    final_score: float
    vector_score: float
    skill_overlap: float
    recency_boost: float
    skills: list[str]

@dataclass
class FusionWeights:
    vector_weight: float = 0.5      # α
    skill_overlap_weight: float = 0.4  # β
    recency_weight: float = 0.1     # γ

@dataclass
class RoutingContext:
    skill_candidates: list[SkillCandidate]
    subagent_candidates: list[SubAgentCandidate]
    fused_ranking: list[FusedCandidate]
    suggested_skills: list[str]
    prompt_block: str               # 注入主控 system 的 markdown
```

**Skill 重叠：**

```python
overlap = len(set(agent.skills) & skill_names) / max(len(skill_names), 1)
final_score = α * vector_score + β * overlap + γ * recency_boost
```

`recency_boost`：若 `agent.stats.last_used` 存在且在 24h 内则为 1.0，否则 0.0（Phase 2 简化实现）。

### 3.4 `agent/context_compressor.py`

```python
@dataclass
class CompressionConfig:
    keep_recent_turns: int = 10

@dataclass
class CompressionResult:
    messages: list[dict]
    summary: str | None
    compressed: bool

def compress_messages(
    messages: list[dict],
    config: CompressionConfig,
    summarize: Callable[[list[dict]], str] | None = None,
) -> CompressionResult:
    """
    1. 分离 system 头
    2. 按 user/assistant 配对计 turn
    3. 保留最近 keep_recent_turns 轮完整消息
    4. 更早消息交给 summarize()，无 summarize 时用占位摘要
    5. 返回 [system?, summary_msg, ...recent]
    """
```

**Turn 计数规则：** 每个 `role=user` 开始新 turn，直到下一个 `user` 之前的消息属于同一 turn。

## 5. 三重路由时序（实现级）

```python
def prepare_routing(agent, query):
    skills = agent.skill_router.identify(query, top_k=settings.routing.skill_top_k)
    agents_raw = agent.subagent_index.search(
        query, assistant_id=agent.assistant_id, top_k=settings.routing.subagent_top_k
    )
    subagent_candidates = [SubAgentCandidate(...) for ... in agents_raw]
    registry_agents = {a.agent_id: a for a in agent.agent_registry.list_by_assistant(...)}
    # enrich skills from registry
    ctx = fuse_routing(skills, subagent_candidates, settings.fusion_weights)
    ctx.prompt_block = format_routing_prompt(ctx)
    return ctx
```

Orchestrator 在 `run_turn` 前将 `routing_context.prompt_block` 作为额外 system 消息插入。

## 6. 错误与降级

| 场景 | 行为 |
|------|------|
| Skill 目录为空 | `skill_candidates=[]`，主控自执行或 create |
| 向量索引为空 | `subagent_candidates=[]`，仅 Skill 路由 |
| embedder 失败 | 跳过 L2，仅 L1 关键词 |
| summarize 未配置 | 压缩时用固定模板摘要旧 turn 数量 |
| dispatch 目标不存在 | tool 返回 error JSON，主控继续推理 |
