## Git 提交计划（Phase 2）

按 TDD 小步提交，建议顺序：

```
docs: add detailed design and implementation plan
test(routing): add fuse_routing cases
feat(routing): implement fuse_routing and RoutingContext
test(vector): add vector store and embedder cases
feat(vector): add JsonVectorStore and HashEmbedder
test(skill): add skill router and index cases
feat(skill): implement SkillRouter and skill index
test(subagent-index): add subagent vector search cases
feat(vector): add subagent index synced with registry
test(compression): add context compressor cases
feat(compression): keep recent 10 turns with summary
test(memory): add memory manager snapshot cases
feat(memory): load MEMORY/USER frozen snapshot
test(tools): add orchestrator tools cases
feat(tools): dispatch/create/search/identify tools
test(agent): triple routing integration
feat(agent): wire prepare_routing into EvoluxAgent
```

每个 `feat` commit 前必须 `pytest` 全绿。
