# Git Skill

When the user asks about version control:

1. Run `git status` to understand the working tree.
2. Prefer small, focused commits with clear messages.
3. Before merging, summarize diff scope and risk.
4. Never force-push to shared branches without explicit approval.

Common commands: `git status`, `git diff`, `git log --oneline -10`, `git add`, `git commit`.
